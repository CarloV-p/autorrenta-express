# AutoRenta Express

Sistema de Gestión de Alquiler de Vehículos desarrollado en Java (JDK 17) aplicando Principios SOLID, Patrones de Diseño GoF y GRASP.

## Tecnologías
*   Java 26
*   Maven
*   Java Swing (UI)
*   SQLite (Persistencia)
*   JUnit 5 (Pruebas)

## Cómo ejecutar el proyecto
1. Clonar el repositorio: `git clone https://github.com/CarloV-p/autorrenta-express.git`
2. Abrir el proyecto en Apache NetBeans (File > Open Project).
3. Esperar a que Maven descargue las dependencias.
4. Ejecutar la clase `Main.java` ubicada en `pe.edu.utp.autorenta`.
